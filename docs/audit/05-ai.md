# 05 · AI 系统调研

范围：src/ai/（11 文件）+ ai-genome.js + persona.js。

## 现状
- 感知→决策→行动三层：perception（空间哈希+FOV+LOS+雾）/ senses（听觉误差模型）/ info（队内黑板衰减+通信半径）/ decisions（botObjectiveRaw 优先级链 ~477 行）/ actions / roles / buys / tactics（H1-H10 融合）/ oppmodel（H11 对手建模）
- 难度体系：easy/normal/hard + hell 1-12 阶梯（基因插值/GA/DQN/军备竞赛）
- 公平性工程完成度高：视野上限、听声模糊、通信衰减、转身惩罚 ×0.25、瞄准限速、后坐力恢复克制

## Bug / 死配置
- A1 **晚安弹分支死代码**：decisions.js:821-828 外层 if 无条件 return，内层 roundTime>55 永不达 → T 方残局不进点
- A2 受击反应 bug：`Math.min(e.reaction, d.react*1.2)` 空闲时 reaction=0 → 0 无反应延迟，背袭立即反击
- A3 tradeUsed/peekCount 跨回合不重置 → 整场只能补枪 2 次、探身 3 次
- A4 T 侧 spread 全偏一侧：assignRoles T 分支不设 anchorIdx → 全队挤同侧
- A5 objBombState 死回退分支
- A6 **view 参数全线失效**：BOT_AI.MAX_VIEW=720 < 所有难度 view → 一律截断，任何难度视野相同（还误导 GA 训练）

## 公平性暗桩
- B1 CT 反应加成"幽灵乘子"：roundTime<45 时 CT 全队 reaction ×0.4-0.6，不受难度影响、无注释、45s 突变
- B2 H11 intel = 授权级透视（回合初读 CT 防守分布、全图消息、30s 实时位置流），全库唯一违反"非透视"自设规则处，建议加 fairPlay 开关+延迟+抖动
- B4 bot 急停一帧归零（完美 counter-strafe），建议 80-150ms 减速斜坡

## 重复 / 性能
- C1 LOS 射线同帧双算（core.js:161/178 相同 aimGone 表达式）
- C2 两套并行听觉模型（senses.js vs decisions.js:626-647）
- C3 botObjectiveRaw 巨型优先链（25 个 early-return、魔数散落），建议优先级模板数组化
- E1 每 bot O(n) 扫描叠加（separation/枪声轮询/los），可复用 SPATIAL_CELL 空间哈希
