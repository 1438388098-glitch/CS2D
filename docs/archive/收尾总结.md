## 二、训练管线（三脚本）

```
scripts/prepare-imitation.mjs  模仿学习预训练：跑规则 AI 对局，按几何/语义标签监督训练网络
  → 产出 train/output/net-imitation-pretrain.json（当前 33 维 × 18 输出，一致率 75-86% 波动）

scripts/train-dqn-worker.mjs   训练 worker（每个 worker 独立环境 + 回放 + 网络）
  → 奖励：per-bot 击杀归属/助攻/安弹/阵亡/eco 纪律/保枪/情报（首次接触敌情 +1.5）
  → 当前参数：33 维观测、18 输出、NET_DECISION_S=0.3、N_STEP=3、Double DQN（trainStepDouble）
  → 对手池：CT 70% 规则 / 30% 池 checkpoint（自对弈）
  → 每 10 万步上报 checkpoint 给主进程

scripts/train-dqn.mjs          训练主进程：8 worker 池 + 快评入池（24 回合 ≥45% 门槛）+ 96 回合双对手终评
  → 用法：node scripts/train-dqn.mjs [stepsPerWorker] [workers]
  → 终评候选 = 各 worker 终态权重 + pool/ 目录全部 checkpoint
  → 最佳导出 train/output/net-weights-trained.json
```

## 三、有效 / 无效实验清单（诚实记录）

### ✅ 有效（叠加后 33% → 49%）
1. **per-bot 奖励流**：击杀/安弹/阵亡按 bot 归属（多智能体信用分配）——loss 从 50-60 降到 8-11
2. **33 维团队观测**：13 基础 + 5 队友 + 3 自身（身份/角色）+ 5 团队因子（经济/武器/甲/队友到齐/敌情）+ 敌人 lastKnown 位置 + 队友意图广播 + 地图归一化
3. **情报奖励**：首次看到/听到敌人 +1.5——网络学会主动探测（peek 动作从 3% 升到第一），+3-4pp
4. **角色展平修复**：netAct 只在 LIVE 决策（BUY 阶段 IGL rotate 曾把全队角色展平成主攻点）

### ❌ 无效（有数据，勿重复）
| 实验 | 结果 | 原因 |
|---|---|---|
| 对手池自对弈（CT 30-50% 池权重） | 无增益 | 快评 12 回合噪声大（±15pp）、池权重更新过频造成非平稳；45% 门槛后仍无增益 |
| 安弹改造（持包者强制 main + 护航规则 + 护包/清点奖励） | 31-39%（退） | 护航吸队友破坏分路节奏 |
| 36 动作节奏维度（×2 节奏） | 38-45%（退） | 动作空间膨胀 + 0.3s 间隔样本效率下降，节奏学不出 |
| 18 动作 + 0.6s + n-step(3) + Double DQN | 31-42%（退） | n-step 与宏观决策间隔不匹配（1.8s 视野跨度过大），且预训练质量波动 |
| 0.3s 间隔 + 18 动作 | 35-37%（进行中被终止） | 高频决策 + 粗动作 → 意图抖动；预训练 75.1% 起点低 |
| 回合加速 20s | 基线 38%→13% | 压垮 T 战术周期（分路→进点→安弹来不及） |

### ✅ 有效的系统改进（保留）
- **评估流程**：终评包含 pool/ 全部 checkpoint（10 万步 checkpoint 多次强于过拟合终态）
- **快评门槛 45%**：防弱权重污染对手池
- **经济场景轮换**：seed%3 覆盖 eco / 中局 / 反ECO（双方同经济，公平）
- **NET_DECISION_S=0.3 游戏内保留**：规则 AI 各难度平衡正常，安弹率更健康（平衡回归验证）

## 四、关键结论

1. **49% 是当前架构（宏观决策网络 + 规则执行层 + 公平能力）的稳定上限附近**：多次实验（per-bot/33 维/情报/对手池/36 动作/n-step）峰值全部收敛在 46-52%，96 回合评估 ±7pp。
2. **训练胜率 35-40% 正常**：ε-greedy（0.08）× 5 bot 的团队探索代价 + 训练种子空间大于评估，真实能力看评估（argmax 96 回合）。
3. **评估对种子极敏感**（±10pp）：单种子 96 回合不可靠，关键对比需多 seedOffset（900/913/926）平均。
4. **T 是进攻方**：49% = 公平对局下把规则 T 的劣势（33%）基本打平，CS 进攻方 50% 即强队水平。
5. **过拟合模式**：所有配置都是 10 万步峰值 → 20 万步退化（固定规则对手被 exploit），训练步数 10-12 万步为宜。
