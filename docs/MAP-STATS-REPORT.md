# CS2D 空间特征对比报告（A1/A2）

- 日期：2026-08-02
- 输入：CS2D 三张 ASCII 地图 + 官方 CS2 radar（de_dust2 / de_mirage / de_inferno）
- 工具：`node test/map-stats.mjs`

## 指标说明

| 指标 | CS2D | 官方 radar |
|---|---|---|
| Open% | 可走开放格 /（开放+墙体） | 雷达图 bounding box 内可走地面像素格占比 |
| Cover | 掩体格（C/^/=/o/D）每 100 个开放格 | 非地面墙体像素格每 100 个地面格 |
| Areas | 4 邻接连通开放区域数量 | 同上 |
| AvgRun | 横/纵开放连续段平均长度 | 同上 |
| Runs>12 | 长度 >= 12 格的横/纵连续开放段 | 同上 |
| T->A/B | aStar 路径时间（秒） | 出生点到点位归一化欧氏距离 x10 |

## 结论

1. CS2D 的开放占比明显偏高：dust2/canal 达到 65.8%/86.1%，官方三图集中在 30%-49%。
2. CS2D 墙体/掩体密度远低于官方：官方雷达墙体密度约 103-238/100 格，CS2D 仅 3.5-4.9/100 格。这解释了“设计太空、打起来像广场”的体验。
3. CS2D 三图各自只形成 1 个超大连通开放区；官方图在雷达分辨率下出现多个分区（mirage 58 个、dust2 6 个、inferno 3 个），空间节奏更碎。
4. 官方图的长直段数量更多但墙体和房间同时密集，说明官方依赖“长枪线 + 密集掩体”的组合，而不是单纯拉长走廊。
5. A3/A4 据此落地：三图新增招牌战术区与可破坏木箱，用动态掩体补密度，同时保留原有薄墙/高台/水域/油桶机制。
