## 2. Godot 移植架构决策

| 决策项 | 结论 | 理由 |
|---|---|---|
| 子弹判定 | **自研网格 DDA 直译，不用 RayCast2D** | 瓦片字符语义（穿透规则）+ fireRay/los 6px 步长对称不变量 + 确定性 |
| 投掷物 | **自研伪抛物线，不用 RigidBody2D** | h 伪高度/阻尼/反弹系数/水面涟漪无法刚体表达 |
| 伤害数字/弹孔/粒子 | **自研**（Node2D._draw），不用 GPUParticles2D | 发射随机不可控，破坏 seed 回放；MAX_PARTICLES=600 池化 |
| 烟雾团 | **逻辑实体**（状态数组供 LOS/子弹读取）| combat L217 子弹被烟挡、los 被烟挡，不能纯表现化 |
| 武器数据 | `WeaponData.gd`(Resource) + 13 个 `.tres` + `WeaponDB` autoload | 编辑器调参友好、与 ballistic 解耦 |
| 半自动边沿 | `_physics_process` 维护 was_down 轮询 | InputEvent 事件流会连发/漏发 |

### 2.1 结构
```
autoload/
  Rng.gd / EventBus.gd / WeaponDB.gd / GameState.gd / AISignals.gd
主场景/
  Game.gd (Node, _physics_process 驱动 update 60Hz)
  Combat.gd / Ballistic.gd / Grenades.gd / Bomb.gd  (static funcs 操作 GameState)
```

## 4. 难点与风险

### 4.1 武器系统↔AI 双向紧耦合（最高风险）
- **combat→AI（写）**：fireWeapon L123-125 曝露 lastKnown（不受听觉门控）；destroyCrate/explodeBarrel 同类曝露；lastShot(hearGunshot 按 name 去重)；applyDamage 写 lastDmgFrom(受击反击)；grenades blind/lastSound；killEntity report(MSG.KILL)。
- **AI→combat（调用）**：ai/actions.js 调 fireWeapon/reload/pickup/throwGrenade；trigger 由 actions 帧更新。
- **对策**：保留"实体资源直写 + GameState 共享"，仅 HUD/音效改 signal。`aiParams.peekSkill/counterStrafe/spreadMult/nadeMult` 注入点必须完整保留。

### 4.2 命中判定顺序与确定性
- fireRay「先实体扫描→墙体→烟雾，比 best.t vs wallT」顺序不可变。
- fireRay 与 los 的 6px 步长对称（MapGrid.STEP=6 常量 + 断言测试）。
- 确定性三支柱：单源 RNG（utils.rand→Rng.gd，禁 randf）；hash01 原样移植；固定 60Hz。
- hitPause 冻结：`_physics_process` 首行同步实现"冻结模拟但继续渲染"。

### 4.3 射击手感 60Hz 映射
| 项 | JS | 60Hz 映射 |
|---|---|---|
| 射速 | fireCd=60/rpm | 直接用 60.0/rpm 计时 -=delta |
| 后坐 | 玩家 RECOIL_RECOVER=2.2，bot 1.2 | 两套系数分别落 Game.gd 与 AI.gd |
| 散布 | (spread+moveSpread+recoil×0.6)×rand×π/180 | 逐 pellet 顺序保持 |
| 爆头 | rand()<p | 随机流消费顺序一致 |
| 半自动边沿 | mouse.down && !mouse.wasDown | 轮询，不用事件流 |
| AWP 开镜 | 只对玩家生效 | bot 永远裸狙，不对称保留 |

### 4.4 其他
- render3d-next 有独立 updateGrenades（L2200/2522）——**合并为单一 Grenades.gd 防双源漂移**。
- destroyCrate/explodeBarrel 改写 grid + invalidatePathCache + _shadowRev++——MapGrid 提供等价可变 API。
- `game.entities` 数组顺序影响"先打谁"——与 spawn 顺序一致。
- `game.player` 判定分支保留（bot 测试注入 player.bot=true 等价路径）。
- `diffOf(game)`→`Difficulty.gd` 单例避免循环依赖。

## 6. 验收标准

- A1 同 seed 两次整局，**伤害事件序列完全一致**（audit7-damage）。
- A2 随机数消费次序一致（audit4d/4f）。
- A3 弹道纯函数逐例相等（ballistic/weapons-falloff/awp-armorpen/verify-awp）。
- A4 蒙特卡洛 AK/AWP 命中率、TTK ±2%（audit2）。
- A5 nadeTrajectory 预览与真实飞行 ≤1px（fx-nade-trail）。
- A6 确定性 FX 输出一致（fx-weapon-fx/fx-impact/fx-smoke-trail/fx-boom/fx-damage-arc）。
- A7 AI 感知联动回归（senses/fx-ai-intel/ai-tactics）。
- A8 60Hz 等价（AK 6 tick/发、AWP 射速、recoil 曲线）。

实施顺序：Ballistic→Combat→FX→Grenades/Bomb→AI 桥→集成回放；以 audit7-damage seed 双跑差分作每阶段回归门槛。
