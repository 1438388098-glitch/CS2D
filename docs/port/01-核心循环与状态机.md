requestAnimationFrame(loop)
  frame = min(rawFrameMs/1000, 0.1)
  acc += frame

## 2. Godot 移植架构

### 2.1 主循环替换

| JS | Godot |
|---|---|
| `requestAnimationFrame` + 累加器 | `_process(delta)` 渲染帧；`_physics_process` 物理帧（60Hz） |
| 固定步长 FIXED=1/60 | `Engine.physics_ticks_per_second=60` + `physics_jitter_fix=0` |
| steps<8 | `Engine.max_physics_steps_per_frame=8`（默认已 8） |
| 倍速循环 | `_physics_process` 内 `match.tick(FIXED)` × speed |

**方案 A（推荐）**：`_physics_process` 直接等于一个模拟步；渲染在 `_process`。注意 `physics_jitter_fix` 必须为 0 保证 delta 严格 1/60。
**方案 B（保守）**：保留累加器在 `_process`——不建议，与 Godot 物理节拍解耦且丢插值保证。

### 2.2 场景树

```
res://main.tscn
└── Main (Node) [extends GameMain]
    ├── GameLoop (Node)          # _physics_process 固定步长
    │   └── Match (RefCounted)   # 不在场景树
    ├── World (Node2D)
    │   ├── MapRoot (TileMapLayer + 静态层)
    │   ├── EntityVisuals (Node2D)   # 实体代理，按 Match 数据插值
    │   ├── ProjectileVisuals (Node2D)
    │   ├── ParticleFX (池化节点)
    │   └── EffectRoot (Node2D)      # decals/ripples/impact
    ├── Camera2D
    ├── HUD (CanvasLayer)
    ├── InputSystem (Node)
    └── AudioSystem (Node)
```

### 2.3 事件总线 → 信号

game.js 循环内 emit 清单：`hideMenu/hideEnd/closeBuy/scoreboard/unpause/objtextShow/flash/dmg/lowhp/holdbar/objtext/banner/bannerHide/toast/sfx/whistle/buyUpdated/refreshScoreboard`。

```gdscript
# autoload: SignalBus.gd
extends Node
signal sfx(payload: Dictionary)
signal event(name: String, payload: Variant)
```
- 信号只做展示方向，不参与决策（与 JS bus emit 无返回值一致）。
- handler 异常隔离：JS try/catch → GDScript `call_deferred` + 约定 UI 不抛错。
- 重开对局断开旧连接（订阅者生命周期管理）。

### 2.4 输入系统
- DOM 事件 → Godot `Input` + `_unhandled_input` + `Input.mouse_mode=MOUSE_MODE_CAPTURED`。
- FPS pointer lock（input.js L162-193）→ 鼠标捕获；`_mlookDx/_mlookDy` 累积保留，**物理步统一结算**（FPS 增量瞄准一物理步一消费）。
- mousedown UI 命中（L195-215）→ Godot GUI `gui_input` 天然隔离。
- `setKey/setMouse/setMouseDown`（L333-344）保留公开 API（测试注入）。

### 2.5 多线程与性能
- **禁止把 `Match.tick()` 扔 Thread**：确定性单线程。
- 每帧分配禁令：对象池 + 预分配 Array（`resize` 代替 push/pop）。
- 实体 ≤11 个，`collideCircle` 只查相邻瓦片——Godot RID 无必要。

## 6. 验收标准

1. **确定性**：同 seed（4242/20260804）两次完整对局逐帧指纹一致；对拍 JS 关键轨迹。
2. **状态机**：MENU→BUY→LIVE→END→(BUY|finishMatch) 全转移自动化验证；含换边（ROUND.SIDE_SWAP_AFTER+1）、加时 4:4、OT 换边。
3. **帧节拍**：1000 个 `_physics_process` delta 恒 1/60；倍速 1/2/4/8 下 game.time 增速正确。
4. **输入闭环**：setKey/setMouse 注入等价；FPS 增量瞄准一物理步一消费。
5. **性能**：headless 10 万步 <60s。
6. **无泄漏**：50 回合后内存平稳。
7. **headless**：`godot --headless --script test/run_all.gd` 跑通。
