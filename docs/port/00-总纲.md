## 2. 三大架构决策（所有模块强制遵守）

### 决策 A：纯逻辑与场景树解耦
- 核心对局逻辑 = `RefCounted` 数据类 + 纯函数 `tick()`，**不挂 SceneTree**。
- 视觉节点 = "实体数据显示器"，每帧读快照插值。
- 理由：保住 headless 测试（JS 的 `simulate.js` 能在 Node 跑整局）；`update(game, dt)` 与 DOM 完全解耦。

### 决策 B：确定性三支柱
1. **单一种子 RNG**：`WorldRand`(autoload) 移植 mulberry32；**禁止** `randf()`/`RandomNumberGenerator`。
2. **固定 60Hz**：`_physics_process` + `Engine.physics_ticks_per_second=60` + `physics_jitter_fix=0`；不重建累加器（`max_physics_steps_per_frame=8` 与 JS `steps<8` 同语义）。
3. **全自研空间判定**：碰撞（圆-瓦片 `collideCircle`）、寻路（A*）、LOS（6px 步进）全部直译，**不用 Godot PhysicsServer / NavigationAgent2D / RayCast**。
   - 理由：物理引擎跨平台/精度不可复现（破坏 audit4b 逐帧指纹）；瓦片字符语义（`=`薄墙可穿、`≈`深水挡弹、`C`低掩体、`^`高台）无法映射到物理体。
   - 例外：Godot physics 仅用于**表现层**（子弹射线可选用、3D 低模碰撞），AI 感知绝不使用。

### 决策 C：数据资源化
- 武器表 → `WeaponData.gd`(Resource) + 13 个 `.tres`。
- 地狱阶梯（H1-H12 参数 + DQN 权重）→ `res://data/hell_ladder.json`（新增 `train/deploy-godot.mjs` 导出）。
- 地图 → 脚本从 `src/official-maps.js` 抽取 JSON → `MapData.gd` + TileMapLayer。
- 权重 JSON 是**纯数据**（`{input,hidden,output,iw,ow}`），GDScript `JSON.parse_string` 无损。

## 3. 数据流契约（跨模块必须一致）

```
main.js 主循环（固定步长 1/60, 最多 8 步/帧）
  └─ update(game, dt)                [game.js L494]  ← 每物理步
       ├─ hitPauseT 冻结检查（提前 return）
       ├─ game.time += dt
       ├─ modeDef.update(game, dt)   [模式钩子]
       ├─ updateTimers()             [状态机 BUY→LIVE→END]
       ├─ updatePlayer()             [玩家输入→移动→射击]
       ├─ updateBots()               [AI：perception→decisions→actions→smooth]
       ├─ updateGrenades()           [投掷物飞行/爆炸]
       ├─ 实体移动 + collideCircle + 卡死重路由
       ├─ 粒子池 / drops / tracers / impacts / decals 维护
       └─ 相机 / 瞄准 / HUD 事件
  └─ 渲染分派：viewMode==='fps' ? render3d* : render()
```

**时序契约**：`game.time` 累加先于 AI 更新；决策先行、位移后置；`updatePlayer→updateBots→updateGrenades→物理`顺序不可变。

## 4. 确定性基座（第一优先实现，M0/M1）

### 4.1 mulberry32 精确移植
JS（`src/ctx.js` L3-12）：
```js
function mulberry32(a) {
  return function() {
    a |= 0; a = a + 0x6D2B79F5 | 0;
    let t = Math.imul(a ^ a >>> 15, 1 | a);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  }
}
```
GDScript 坑位：
| JS 运算 | GDScript 替代 |
|---|---|
| `a |= 0`（int 截断） | `a = a & 0xFFFFFFFF`（再按有符号解释时 `if a > 0x7FFFFFFF: a -= 0x100000000`） |
| `>>> 0`（无符号右移） | `x & 0xFFFFFFFF` |
| `Math.imul(a,b)` | `a * b` 后 `& 0xFFFFFFFF`（GDScript int 64 位，需截断） |
| `/ 4294967296` | float 除法（双精度同 JS） |

**验证**：`test/core-infra.mjs`、`audit4b-determinism.mjs`（同 seed 60 万帧指纹）必须复现。

### 4.2 确定性哈希 `hash01`（fx 模块共用）
- 源自 `ambient-fx.js` L11-21（FNV-1a 变体），被 weapon-fx/impact-fx/smoke-fx/boom-fx/anim-fx 共用。
- 移植同样需 `& 0xFFFFFFFF` 截断 + 手写无符号右移。
- 先做 `hash01.gd` 单元测试对照，防最隐蔽的坑。

### 4.3 帧节拍验收
- 连续 1000 个 `_physics_process` 中 delta 恒为 1/60（`physics_jitter_fix=0`）。
- 倍速 1/2/4/8（cyber/spectate）必须在 `_physics_process` 内同步循环 ×speed，禁止借道 `_process`。
- `skipSpectatedRound` 用 while 循环 `update(g,0.05)` 最多 5000 次（L356-361）——移植为 `match.tick(0.05)` 循环。
