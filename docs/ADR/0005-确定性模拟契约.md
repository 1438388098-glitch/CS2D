# ADR-0005：确定性模拟契约

- 状态：已接受（长期有效）
- 日期：2026-09-09（自治迭代期间成文）

## 背景

项目大量依赖可复现性：同 seed 双跑指纹回归（`test/manager-determinism.mjs`）、特效 spec 可被测试断言、LAN 双端同 seed 同构模拟。任何一处非确定性都会让这套体系静默失效。

## 决策（硬规则）

1. **游戏逻辑内禁 `Math.random`**：用 `ctx.rand`（seed 驱动的 PRNG 单例）或 `utils.js` 的 `hash01` 确定性哈希。渲染端表现层（如天气粒子）也用固定 seed 派生，保证同 seed 同画面。
2. **禁 `Date.now` 写入对局逻辑状态**：计时用 `game.time`（模拟时钟）。历史例外：`pushNews` 的 `t`、`hltvHistory` 的展示用时间戳——只作展示元数据，不参与逻辑判定，勿模仿扩大。
3. **特效 = 纯 spec 函数 + draw 函数**：spec 由输入参数确定性导出（可断言），draw 只消费 spec 画图（可传 stub ctx 测试）。参考 `src/boom-fx.js` + `test/fx-boom.mjs` 的模式。
4. **模块级单例资源的并发约束**：`ctx.rand` 是全局单例流——需要独立随机流的双跑测试必须**串行**执行，不能交错（会被对方消耗随机流）。
5. **模拟逻辑与渲染态分离**：渲染私有状态（如 `stepFXState`）挂在渲染模块的 Map 里，不进存档、不进 LAN 同步。

## 违反后果的历史案例

- 双跑确定性测试曾因两局交错共享 `ctx.rand` 而 FAIL（不是引擎 bug）。
- `PARTICLE_STYLES` 尾逗号非法色值被 canvas 静默忽略 → 粒子颜色取决于上一帧残留（存活多日的视觉 bug，靠契约测试 + 实机验证才抓到）。
