# ADR-0003：经理模式时间流采用「赛季 = 一年」简化口径

- 状态：已接受（含已知权衡）
- 日期：2026-09-10（PR#1 引入时间流时确立）

## 背景

电竞经理模式的时间流（PR#1）按"每场玩家比赛 +1 天"推进日历，但一个赛季只有约 19-20 个比赛日；`nextSeason` 结算时直接把日期跳到"下一年 01-05"。

## 决策

接受"赛季 ≈ 一年"的装饰性口径：日期主要用于氛围展示与月度发薪触发锚点，不追求模拟真实历法。

## 已知权衡（不要当 bug 修）

- 一个月 20 个比赛日从 01-05 起步，通常跨不到每月 1 号 → **monthlyPayroll 与圣诞休赛期在正常流程中几乎不可触发**。要激活需要经济节奏设计决策（例如改为赛季节点发薪），见 GitHub Issue。
- `nextSeason` 直接跳年绕过 advanceDate 钩子，因此结算处显式调用 `maybeRotateYear` 立即发布年度 Top 20。
- 旧档迁移链 VERSION 1→4 在 `migrateManagerState`，新增时间相关字段必须兼容补默认值。
