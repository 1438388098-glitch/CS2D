# ADR-0001：零 npm 运行时依赖

- 状态：已接受
- 日期：2026-08（项目起点）

## 背景

CS2D 是纯浏览器游戏，起步时可选 Webpack/Vite/Phaser/PixiJS 等全家桶。

## 决策

运行时零依赖：原生 ES Modules + Canvas 2D，服务端用 Node 原生 `http` + 手写 WebSocket 中继（RFC 6455）。构建工具仅用 `node --check` 级别的自研脚本（`scripts/check-syntax.mjs`）。

## 后果

- 正面：无 node_modules、无 lockfile、无 supply chain 面积；克隆即玩；CI 三分钟跑完；任何机器 `npm start` 就能跑。
- 负面：需要自己维护测试 runner、WebSocket 握手、打包策略（目前无打包，靠浏览器原生 ESM）。
- 约束传递：任何新依赖（包括 devDependencies）需要新 ADR 论证。
