# 10 分钟冒烟试玩清单（PLAYTEST）

自动化测试抓不住"看起来不对"的问题——历史上最严重的两个视觉 bug（闪光弹白屏从未可见、粒子颜色非法）都是靠人眼发现的。**每批判量推送合并后，按本清单玩一遍**，全部通过才算验收。

## 准备

```bash
npm start        # http://localhost:8080
```
浏览器打开后 **Ctrl+F5 强刷**（静态资源有强缓存）。

## 清单（约 10 分钟）

### 开局与战斗（3 分钟）
- [ ] 主菜单渲染正常，模式卡片图标显示
- [ ] 开一局经典爆破：走路流畅、无掉帧感
- [ ] 开一枪：枪口火光、弹壳、墙上弹孔、火花条纹都可见
- [ ] 打中 bot：伤害数字出现且大小随伤害变化、命中标记、爆头金色
- [ ] 被 bot 打中：屏幕红晕 + 方向弧 + 准星扩散
- [ ] 击杀 bot：击杀信息条带武器图标、爆头有 ☠、击杀标签（KILL/爆头!）

### 道具与交互（3 分钟）
- [ ] 买一颗闪光弹并引爆：**屏幕真的白了**（径向渐变过曝，不是没反应）
- [ ] 烟雾弹：烟团体积感、边缘飘散
- [ ] HE：爆炸冲击波 + 屏幕震动
- [ ] 站进水里：涟漪、水花、移动减速
- [ ] 买枪/加甲：HUD 资金旁飘出 -$ 浮动提示

### 目标物与地图氛围（2 分钟）
- [ ] 下包后：C4 蜂鸣伴随红色警报环扩散（倒计时越急环越快）；**最后 10 秒屏幕边缘红晕随蜂鸣呼吸**
- [ ] 小地图：下包/拆弹/爆炸位置出现彩色 ping 扩散；**阵亡位置出现 1.8s 渐隐 ✕ 标记**
- [ ] **残局 1vN**：队友全灭后屏幕出现金色「残局 1vN」badge
- [ ] 受伤的 bot 名牌上方有血条细条
- [ ] 换一张有水的图（如 canal）：浅水亮线、深水焦散暗斑都在动
- [ ] dust2 沙霾、canal 雾团；**harbor 雨天 + 水面自动涟漪 + 海风环境音**

### 战斗高光（1 分钟）
- [ ] 爆头：金色粒子迸发（血色之外的金色条纹）
- [ ] C4/油桶爆炸：火星余烬缓升 ~2 秒
- [ ] 对枪开火：枪口下方地面短暂泛光
- [ ] 打带甲目标：伤害数字为蓝色（护甲吸收）

### 收尾（2 分钟）
- [ ] 死亡后观战：**0.9s 击杀者镜头**后切入队友；**左上角显示观战目标信息条**；Q/E 切目标不跳镜
- [ ] 回合结算/全场结算：击杀榜、武器榜显示正常
- [ ] 经理模式：顶栏有日期与「📊 年度 Top 5」按钮，打一场比赛后阵容页出现 HLO 分数
- [ ] Esc/暂停/设置面板可开，音效正常；**设置→准星改颜色/长度进对局立即生效**
- [ ] 屏幕震动强度滑杆（设置→视角）调 0 后受击不再震屏

## 发现问题后

1. 先 Ctrl+F5 排除缓存
2. `npm test` 确认自动化基线是绿的
3. 到 GitHub Issues 检查是否已知；没有就开新 Issue，附：模式、地图、复现步骤、现象截图
