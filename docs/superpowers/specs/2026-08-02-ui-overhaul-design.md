# CS2D UI 与音效全面现代化改造 · 设计文档

- 日期：2026-08-02
- 状态：待评审
- 风格方向：现代竞技 FPS（Valorant/CS2 式：深色玻璃拟态 + 几何语言 + 高信息密度 + 克制动效）
- 技术路线：游戏世界渲染保持 Canvas；**HUD 与界面全部 DOM 化**（HTML/CSS 重构，动效/渐变/图标/响应式更易维护）；音效保持 WebAudio 程序化合成但**重构混音架构与声音设计**

---

## 1. 背景与目标

CS2D 玩法系统已成熟（三图深化、AI、平衡、瞄准手感均已完成），但视觉与听觉表现停留在"功能可用"层面：大量半透明黑块 HUD、纯文字按钮、无图标资产、电子味音效、无混音治理。本次改造只动表现层，**不动玩法逻辑、不动平衡数值、不动 AI**，目标是让 CS2D 达到"可对外展示"的观感水准。

**成功标准**：
1. 游戏内 HUD 全部 DOM 化，任何界面元素可被 CSS 动画/渐变/响应式驱动
2. 全部界面统一设计 tokens（色彩/字体/间距/圆角/阴影/动效），无散落硬编码
3. 音效系统分组混音 + 压缩限幅，多音效叠加无爆音；武器音色按枪械分类，声音有距离感与材质感
4. 主菜单/记分板/购买/设置/结算五类面板全部升级
5. 改造期间 selftest/simulate/hell-battle/smoke-test 四套回归持续全绿

## 2. 现状诊断

### 2.1 UI 现状问题清单

| 模块 | 现状 | 问题 |
|---|---|---|
| HUD 状态面板（hud.js） | 左下 `rgba(0,0,0,0.55)` 黑块，数字+两条纯色条 | 无设计感；血条/护甲条无分段质感；无武器图标；换弹仅文字"换弹中…"；金钱无层级 |
| 计时/比分（hud.js） | 顶部居中黑条 180×34 | 与竞技 FPS 的"角落信息区"惯例不符；买枪倒计时直接印在计时条下方 26px 处，无视觉容器 |
| 弹药（hud.js） | 右下右对齐文字，手雷仅一行文本 | 弹药数字无大字层级；无投掷物图标；无换弹进度表现 |
| 小地图（hud.js renderMinimap） | 240×180 固定尺寸 + 简单边框 | 无玻璃质感；无缩放按钮 UI；站点/炸弹标记粗糙；玩家箭头朴素 |
| 准星（renderCrosshair） | 十字线 + 间距随 spread 扩张 | 无命中反馈变色（红/白仅有 aimTarget 一种状态）；无开火收缩动画；缺爆头特殊反馈 |
| 命中标记 | 8px 米字，位于鼠标处 | 无爆头区分、无击杀击杀强化标记 |
| 受击方向指示 | 红色三角箭头（Canvas 画） | 可保留但需风格统一（描边+发光） |
| 主菜单（index.html menu） | 单面板双列：文字按钮堆叠 | 无地图预览；难度四按钮无主次；无英雄区/氛围；背景为 canvas 层模糊（可保留改进） |
| 记分板（index.html scoreboard） | 纯文本表格 | 无装备图标/击杀图标；无 MVP 标记；无自己行高亮；无回合历史（1-12 vs 13-24） |
| 购买菜单（renderBuyMenu + index.html buy） | 网格卡片：图标 canvas 缩略+文字 | 武器图标为 canvas 画的小图（drawWeaponIcon），风格粗糙；无分类高亮；无"买得起"引导；无快捷购买提示 |
| 设置页（index.html settings） | 单一列表，键位行内联 | 无分组；无冲突检测；无当前按键高亮 |
| 结算画面（index.html end） | 文字行 + 两个按钮 | 无图表；无本局数据总结（击杀/爆头/伤害）；无 MVP 可视化 |
| 横幅/连杀（banner/streak DOM） | 文字 + scale 动画 | 动画曲线生硬；无图标化（骷髅/火）；连杀无音效配套（音效已有 streak 但简陋） |
| 字体 | 全局 Segoe UI + Microsoft YaHei | 数字无等宽/竞技字体；标题无字重层级 |
| 响应式 | 仅 640/720px 两断点 | 窄屏下 HUD 挤、菜单溢出；无触屏考虑 |

### 2.2 音效现状问题清单（audio.js，250 行全程序化合成）

| 问题 | 说明 |
|---|---|
| 无混音架构 | 单 `master` gain（0.5），所有音效直连；无 SFX/UI/环境/音乐分组；无独立音量设置（只能全局静音） |
| 无动态处理 | 无 Compressor/Limiter；枪声 2 层振荡器+噪声同响时叠加削波爆音（shot 已有 `v*0.35` 第二层，爆炸 boom ×1.4 更明显） |
| 武器音色匮乏 | 只有 shot/awp/pistol/shotgun 四种 patch，AK/M4/SMG/冲锋共用一个"shot"；无枪械辨识度 |
| 无距离-频率衰减 | 距离只衰减音量（线性 1600px），远处枪声不闷；pan 基于 camX 而非玩家耳朵位置（死后无 pan） |
| 脚步无材质 | 一个 bandpass noise 打天下；无地面/金属/薄墙/水区别；静步无音色切换 |
| 无空间感 | boom/awp 无 echo/尾音；地铁图应更空旷无回声反差 |
| 无音高随机 | 同武器每枪音色 100% 相同，机械感强 |
| 无 UI 音效集 | 按钮 hover/click/确认/错误/Tab 开合全部无声 |
| 事件音效缺失 | 低血量无心跳；炸弹倒计时无加速 beep；plant/defuse 无提示音；爆头音效（head）是 1.2kHz 方波，像鼠标蜂鸣 |
| 音乐缺失 | 主菜单/购买阶段/回合间无氛围音（可选） |
| 资源泄漏 | 每个音效 `setTimeout` 1200-1500ms 后 disconnect；高频枪战累积大量 timer + 节点不释放 |
| 音效断尾 | 单声道噪声突发，无 decay 包络层级（如 shotgun 只有 0.22s） |

## 3. 设计原则（现代竞技 FPS 七法则）

1. **信息优先级 > 装饰**：玩家 90% 视觉焦点在准星与角色，HUD 必须边缘化、低干扰、可读于 0.2s；装饰永不闪烁抢戏（除关键警告）
2. **几何语言**：直线 + 切角（chamfer）+ 细描边；不用圆润气泡、不用厚重浮雕、不用多重渐变堆叠
3. **克制动效**：所有动画 120-250ms 内完成；只有击杀/回合/炸弹这类"结果事件"允许大动效；移动端无 hover，靠 active 态
4. **玻璃拟态分层**：背景 rgba(10,13,17,α) + 1px 细边 + 8px 模糊（backdrop-filter 谨慎用，低端机降级纯色）；层级用亮度区分，不用透明度堆叠
5. **阵营色即语义**：CT 蓝 `#4da6ff`、T 橙 `#ffb545` 贯穿所有界面；红色只属于"危险/击杀/受伤"；金色只属于经济/奖励
6. **数字优先**：HP/弹药/计时/比分用等宽竞技数字（Bahnschrift，Win 自带，离线可用），中文字面用雅黑；数字比文字大 2 号优先
7. **一切可配置**：音量分组、小地图缩放、准星样式（可选开关）持久化 localStorage

## 4. 设计系统（Design Tokens）

统一在 `styles.css` 顶部 `:root` 定义，代码中禁止散落色值。

```css
:root {
  /* 色板 */
  --bg-0: #0d0f12;        /* 页面底色 */
  --bg-1: rgba(15,18,22,.92);  /* 面板 */
  --bg-2: rgba(20,24,29,.72);  /* 悬浮条 */
  --bg-3: rgba(0,0,0,.55);     /* HUD 底 */
  --line-1: rgba(255,255,255,.10); /* 细描边 */
  --line-2: rgba(255,255,255,.22); /* 强调描边 */
  --txt-0: #f2f5f8;
  --txt-1: #c7cfd9;
  --txt-2: #8b95a1;
  --ct: #4da6ff;   --t: #ffb545;
  --danger: #ff4d4d;  --gold: #ffd27a;  --ok: #5ecf6a;
  --accent: #ff8a2a;  --accent-hi: #ffa04d;

  /* 字体 */
  --f-num: "Bahnschrift", "Segoe UI", sans-serif;   /* 数字/字母 */
  --f-cn: "Microsoft YaHei", "PingFang SC", sans-serif;
  --f-mono: "Consolas", "Courier New", monospace;   /* 计时秒数 */

  /* 尺寸 */
  --r-s: 4px; --r-m: 8px; --r-l: 12px;
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px; --sp-5: 24px;
  --hud-edge: 16px;               /* HUD 距屏边距 */

  /* 动效 */
  --ease: cubic-bezier(.22,.61,.36,1);        /* ease-out-quart 近似 */
  --ease-in: cubic-bezier(.55,.06,.68,.19);
  --dur-s: .12s; --dur-m: .22s; --dur-l: .35s;
}
```

### 4.1 图标语言
全部内联 SVG（`<symbol>` 精灵表或内联字符串），统一 24×24 viewBox、1.5px 描边、`currentColor` 继承。覆盖：武器 ×15、投掷物 ×3、击杀/爆头/助攻/死亡、炸弹、金钱、设置齿轮、音量、键盘、地图、MVP 星、回合胜利/失败。

### 4.2 动效曲线
- 进场：`--ease` 0.22s + translateY(8px)→0 + opacity 0→1（仅一次）
- HUD 数值变化：opacity 闪烁 0.12s，不位移
- 关键结果（击杀/回合/炸弹）：scale 1.0→1.08 overshoot 0.15s 内回弹

## 5. UI 模块改造设计

### 5.1 主菜单（P0）

**结构**（替换现有单面板）：
- 全屏背景：保留 canvas 生成层（`setMenuBackgroundFromLayer`），升级为"三图轮播/交叉淡入"，前景加网格线（1px rgba 叠层）+ 角落品牌框
- 主容器改为**左右分栏卡片**：
  - 左栏（60%）：**地图选择卡片区**——3 张等宽卡片横排，每张含：canvas 实时缩略预览（已有 layers.miniMap 可直接复用）、地图名、风格一句话（"沙漠遗址 · 均衡"）、悬停描边高亮 `--accent`；选中卡片右下角打"✓"
  - 右栏（40%）：**阵营 + 难度 + 机器人 + 声音 + 开始**——阵营改为两块横向大按钮（CT 蓝渐变 / T 橙渐变，选中时外描边 + 内发光）；难度四按钮改为**四宫格卡片**（每张：等级名 + 一行描述 + 悬停上浮），地狱档展开 H 滑杆保持现有
- 操作说明折叠为"？"按钮弹出（右下角），不再常驻占一半面板
- 保留：Bot 数量选择、静音按钮、设置入口

**验收**：1280×720 与 1920×1080 下无滚动条；3 张地图卡片缩略图正确；键盘 Tab 可遍历全部控件（焦点可见）；开始按钮 Ctrl/Enter 可触发

### 5.2 游戏内 HUD 核心（P0）——DOM 化

从 `hud.js` Canvas 绘制迁移到 `index.html` 静态骨架 + `src/ui-dom.js` 更新器。保留 Canvas 的只有：准星（跟随帧率）+ 小地图（图层重）+ 受击方向（可 DOM）。

**5.2.1 左下状态面板**（原黑块区）
```
┌────────────────────────────┐
│  AK-47  [icon]    HP 100   │  ← 武器名+图标  |  大号血量数字（Bahnschrift 28px）
│  ▓▓▓▓▓▓▓▓░░░░ 100/30 armor│  ← 分段血条（每 25hp 一档明暗）+ 护甲条（蓝）
│  ▓▓▓▓▓▓▓▓▓▓   $ 3250      │  ← 换弹时：进度条替代血条位置（橙色）
│  换弹中 1.2s  [转圈]       │  ← 换弹/开镜/静步状态行（图标+文本）
└────────────────────────────┘
```
- 血条分段：`repeating-linear-gradient` 每 25px 一档，低血（≤25）整体变红 + 呼吸动画 1.2s
- 状态行：换弹（旋转弧线）、开镜（准星图标）、静步（脚印图标）、水中（水波图标，配 splash 音）
- 死亡：面板淡出，显示观战条（左下角：观战对象名 + 左键切换）

**5.2.2 右下弹药区**
- 主弹夹 `28px` Bahnschrift 大字 + `/ 弹药` 次级 + 武器名；空仓时数字红闪
- 投掷物三格图标（HE/闪光/烟），持有时高亮，空时 40% 透明
- 换弹时弹夹数字旁出弧形进度环（CSS conic-gradient，0.25s 更新一次）

**5.2.3 顶部计时/比分**
- 居中窄条：`00:00` 等宽数字 + 左侧 T 比分 `[T 8]` 右侧 `[5 CT]`（阵营色）；条体玻璃化（bg-1 + 细边），宽 200px 高 30px
- 下方 8px 处：购买阶段剩余秒（金）、HELL 等级（火图标）、炸弹倒计时（红、<10s 每秒闪烁）——各自带小图标，不再裸文字

**5.2.4 小地图（Canvas 层保留 + 皮肤）**
- 玻璃底：圆角 8px + 细边 + 半透明暗角；右上角两个小按钮（+/− 缩放，现有 toggleMiniZoom 驱动）；底部中央显示当前地图名（小字）
- 站点标记改圆角方块 + 发光；炸弹改为闪烁菱形；玩家箭头升级为描边三角（白色描边 + 阵营色填充）
- 渲染节流：静止时 2fps，移动/事件时全速（已有 lastMiniUpdate 机制扩展）

**5.2.5 准星（Canvas 保留，渲染升级）**
- 现有十字线保留结构，升级：开火时 gap 回弹动画（recoil 消散即 gap 收缩，60ms）；命中变色（当前 aimTarget 红）保留；**爆头命中**十字线外圈加双点标记；血量 ≤25 时准星四臂末端内收 2px（呼应低血）
- 新增可选：`Settings → 准星动态` 开关（默认开）

**5.2.6 事件型 HUD（DOM）**
- 命中标记：现有 Canvas 米字保留位置，升级爆头时外扩 1.5× + 金色；击杀时加白×3 内收
- 受击方向：保留 Canvas 箭头，加描边 + 发光（`shadowBlur` 仅在受伤时开）
- 击杀反馈：killfeed 卡片加武器小图标 + 爆头徽标（现有 hs 标签改 SVG 头骨）；banner（回合开始）/streak（连杀）改玻璃条 + 图标化（"DOUBLE KILL" 双剑图标）
- 炸弹计时器：底部中央改 DOM 卡片（图标 + 秒数，<10s 红色脉冲）；plant/defuse 进度沿用 holdbar 但加图标与百分比

**验收**：黑块类 `rgba(0,0,0,0.55)` HUD 全部消失；无中文硬编码字体串（除 CSS）；所有数字元素使用 --f-num；FPS 对比改造前下降 < 5%（同机器）

### 5.3 记分板（P1）

- 头部：比分大字 + 回合指示（两个 12 格小方块条：赢=实心阵营色，输=空心，12 回合后换列显示）

### 5.4 购买菜单（P1）

- 布局：左侧**分类标签竖列**（步枪/手枪/霰弹/狙击/冲锋/投掷/装备），右侧卡片网格

- 键盘：数字键 1-7 切分类、点击/回车购买（现有逻辑保持）
- 新增微交互：购买成功 60ms 卡片 green flash + UI 音效（见 6.4）

### 5.5 设置页（P1）

- 分两段卡片：**按键绑定**（现有列表，新增"按键冲突"检测——绑定同键时双方行红边 + 提示）＋ **偏好**（音量分四组滑杆[见 6.1]、小地图缩放默认值、准星动态开关）
- 键位行：`键名 [kbd 样式]` + 当前键高亮（绑定中动画）；Esc 取消绑定保持

### 5.6 结算画面（P1）

- 保留现有：胜负大字/比分/战绩/MVP/按钮
- 新增**数据小结条**：四格图标统计——击杀（骷髅）、爆头（头骨%）、伤害（子弹）、助攻（握手）；**双方比分柱状图**（13 格刻度，两色柱对比）
- MVP 可视化：金星 + 名字放大 1.2× 金色

### 5.7 反馈动效（P2）

- 回合 banner：玻璃条 + 胜利金色/失败灰色 + 左斜角切割（clip-path 切角语言）；进场 scale .9→1 0.18s
- 连杀 streak：图标 + 大字（现有 s1/s2 结构改 tokens 化）
- 死亡画面：现有死亡信息保留，加全屏红角闪 0.25s（CSS）
- 低血：左下血条呼吸 + 屏幕边缘红 vignette 已有（lowhp），改为随 HP 线性透明度（现在只有开关式）

### 5.8 响应式（P2）

- 断点：`≥1280` 完整布局；`900-1279` HUD 收窄（弹药区省投掷物行）；`<900` 状态面板图标化（隐藏文字标签）、顶部比分条缩小、主菜单单列滚动
- 触屏（pointer:coarse）：准星用点击位置；增加移动虚拟摇杆（左半屏）与射击按钮（右半屏）——**标注为可选项，默认不做**（YAGNI，除非用户要求）

## 6. 音效系统打磨设计

### 6.1 混音架构（重构 audio.js 信号链）

```
AudioContext
└─ MasterGain ── DynamicsCompressor ── destination
   ├─ SFX  bus（游戏音效：枪/爆炸/脚步/命中/投掷）       默认 1.0
   ├─ UI   bus（界面音效：hover/click/确认/错误）        默认 0.8
   ├─ AMB  bus（环境：地铁站/风声/心跳/倒计时）          默认 0.6
   └─ MUS  bus（音乐：主菜单/购买/回合主题）             默认 0.5（先只做 0-1 音量，不产内容）
```
- 每 bus：`GainNode` + 独立音量（0-1，默认值如上），**四组音量写入 `localStorage['cs2d_audio']`**，设置页四滑杆（5.5）双向同步
- **Compressor**：`threshold -18dB / knee 24 / ratio 8 / attack .01 / release .25`——一劳永逸解决多音效叠加爆音；枪战高频段自动压动态
- 音量槽位管理：`voiceCount` 上限 24/帧尾清理；同一 name 短间隔（<20ms）合并跳过

### 6.2 声音设计升级

**6.2.1 武器音色按枪分类**（替换单一 shot patch）。每类 = 噪声突发 + 主体振荡器 + 金属敲击层，参数表：

| 类别 | 代表 | 主体频率 | 衰减 | 特征层 |
|---|---|---|---|---|
| rifle | AK/M4/法玛斯 | 170→60Hz square | 0.10s | 2.1kHz 金属敲击 0.05s |
| ak | AK-47 | 150→50Hz | 0.13s | 低频+密度大（低通 2400） |
| smg | MP5/P90 | 240→90Hz | 0.06s | 高频噪 + 弹壳 3.2kHz tick |
| sniper | AWP/SCAR | 90→28Hz sine | 0.32s | 噪底 + 枪栓 0.25s 处卡嗒 |
| pistol | 沙鹰/手枪 | 3200Hz bandpass | 0.05s | 短 |
| shotgun | 喷子 | 1800Hz lowpass | 0.22s | 多弹丸噪（噪声层 x3 错时） |
| knife | 刀 | 1400Hz bandpass Q6 | 0.12s | 挥击风声 0.1s 前置 |

- **音高随机**：每枪 `playbackRate` 0.96-1.04 随机；时长同步缩放
- **距离-频率衰减**：现 `dv = 1 - dist/1600` 保留，新增 `cutoff = 3000×(0.3+0.7×dv)`Hz 低通串联——远枪变闷；`dist > 1300` 时额外衰减 6dB
- **空间感**：boom/awp/shotgun 串联 `DelayNode(0.16s, feedback .22, wet .18)`；地铁图参数改为 `(0.32s, .3, .26)`（地图类型注入，config 读 mapId）
- **脚步材质**：发射时读 `tileAt(x,y)` 地表——平地 bandpass 500-800Hz / 金属贴面 1500-2200Hz / 薄墙 900Hz / 深水 splash 现有 / 静步（Shift）音量 ×0.35 + 低通 1200Hz

**6.2.2 事件音效补齐**

| 事件 | 设计 |
|---|---|
| 低血量心跳（hp≤25） | 每 0.8s 双拍（66Hz 正弦 ×2 + 40ms 间隔），音量随 hp 线性 0.1→0.4 |
| 炸弹倒计时 | 每 1s 短 beep（1200Hz 30ms）；<10s 每 0.5s；<5s 每 0.25s + 频率升到 1600Hz |
| 装弹完成 | 卡嗒（2.8kHz 8ms + 1.4kHz 8ms 双击） |
| 爆头命中 | 现 head（1.2kHz 方波）改"清脆骨感"：1.8kHz sine + 0.03s 噪声尖刺 |
| 击杀确认 | kill 保留低频 + 尾缀 2.1kHz ping（已有结构，加音高随机） |
| plant/defuse | 定时 240Hz 脉冲（每 0.15s，dur 30ms）直到完成——替代纯 holdbar 视觉 |
| 空仓点击 | 1.1kHz 8ms + 0.9kHz 8ms 双 click |
| 回合结束 | win：四音上行琶音 + 大和弦收尾（C5-E5-G5-C6 + C 大三和弦 0.8s）；lose：三音下行 + 低音 130Hz 长衰减 |
| 开局 whistle 保留 | 加第三声 1568Hz（现有两声 1318/1046 后 +0.5s） |

**6.2.3 UI 音效集（UI bus）**

| 触发 | 声音 |
|---|---|
| 按钮 hover | 2.2kHz sine 6ms @0.12 vol |
| 按钮 click | 1.5kHz+900Hz 双 tick @0.3 |
| 确认（开始/购买/设置保存） | 660-880-1100 三连（复用 buy 旋律 @0.6） |
| 错误（买不起/冲突/空仓） | 200Hz 方波 80ms + 180Hz 100ms 低沉 |
| Tab/面板开合 | 500Hz 10ms 短刷（noise bandpass 快速扫频） |

### 6.3 技术治理

- **节点生命周期**：弃用 `setTimeout(disconnect)`——所有音效统一 `src.onended → disconnect`（BufferSource 自带 stop 事件）；尾部节点由 bus 持有引用，bus 音量归零时批量清理
- **initAudio 解耦**：`window.AudioContext` 改为注入（`setAudioContextFactory(fn)`），测试可传 mock；现有 `initAudio()` 保持浏览器入口
- **地图参数注入**：`bindToGame` 已存 game 引用，从 `game.mapId` 读混响参数（metro=长混响，canal=中等，dust2=短）
- **性能**：单帧内 `sfx()` 调用 >24 次时丢弃最低音量者；全部音频节点创建统一走 `makeNode(name)` 工厂便于 profile
- 回归：现有 selftest 不测 audio（无 DOM/无 window），新增 `test/audio-patch.js`：无 window 环境下对每个 patch 建图跑 200ms 不出错、bus 音量归一、voice 上限逻辑（可选但推荐）

### 7.3 渲染与性能

- 改造后跑一次 `test/simulate.js` + 手测 144Hz 屏幕无 HUD 闪烁
