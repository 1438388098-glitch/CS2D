# CS2D 单挑模式 设计文档

> 日期: 2026-08-03 · 状态: 已实现
> 模式 id: `duel`

## 1. 概述

单挑模式是 1v1 MR9 对战：玩家 vs 真实 CS2 选手 AI，地图由主菜单左侧选择，对手与战绩可持久化。入口放在主菜单「娱乐模式」折叠区。

## 2. 流程

1. 主菜单选择「娱乐模式」→「单挑模式」。
2. 模式设置区选择对手（真实 CS2 选手），地图沿用左侧地图选择。
3. 点击「开始比赛」进入 MR9 1v1。
4. 比赛结束后自动记录胜负/击杀/死亡/连胜，并写入最近 20 场历史。
5. 支持一键重置战绩。

## 3. 比赛实现

- 复用经典爆破引擎，`bots=1` 后移除友方 bot，只保留玩家与对手。
- 对手 `aiParams` 由选手 rating 经 `teamDiffParams` 映射。
- 结算通过引擎 `finishMatch` 的 `onFinish` 回调触发，避免 `game.over` 后 update 不执行的问题。

## 4. 存档

- localStorage `cs2d_duel`(version 1)。
- 损坏或版本不匹配时备份并重建。

## 5. 文件与测试

- `src/duel.js`：逻辑与模式注册。
- `src/ui.js`：模式设置区接线。
- `index.html`：娱乐模式卡片。
- `test/duel.mjs`：建档、战绩、存档、真人比赛结算测试。
