# CS2D 第四图设计蓝本 · 边境熔炉

> 状态：蓝本待确认
> 定位：战术转点图 · 室内外混合 · 不同路线适配不同武器 · 大图

## 1. 设计定调

- 节奏：战术转点图，信息与道具博弈优先。
- 机制：室内外混合，两套交战逻辑。
- 武器：不同路线适配不同武器。
- 规模：约 150×140，接近官方大图。

## 2. 总体结构

- T 南，CT 北，A 西，B 东。
- 西半区：室外集装箱场 + 吊机高台，长枪/步枪路线，但视野分段。
- 东半区：室内废弃厂房 + 多层货架，短枪/喷子路线，近距离转角。
- 中路：南北贯通，外有断桥、内有地下通道，控制中路 = 控制转点。

## 3. 路线语言

| 包点 | 路线 | 风格 | 武器适配 |
|---|---|---|---|
| A | A大 | 室外主路，开阔但暴露 | 步枪/狙击（分段视野） |
| A | A小 | 仓库侧门，窄通道 | 冲锋枪/喷子 |
| A | A地道 | 绕后慢路 | 多功能 |
| B | B大 | 室内主廊，中距 | 步枪 |
| B | B小 | 货架巷道，近战 | 冲锋枪/喷子 |
| B | B地下 | 绕后通道 | 多功能 |
| 中路 | 断桥/地下 | 信息与转点 | 全武器但高风险 |

## 4. 区域四层

1. 出生缓冲：出门 2-4 秒不被直接压制。
2. 信息争夺区：双方抢视野、抢位置。
3. 核心交火区：掩体密度最高。
4. 包点内部：安装/拆除、残局博弈。

## 5. 设计约束

- 任意两个核心交战点至少两条独立路线。
- 禁止一眼看穿长街，视野分段。
- 掩体成链，禁止散装孤岛。
- 包点差异化：A 室外、B 室内。
- 不同路线有明确时间差与暴露差。
