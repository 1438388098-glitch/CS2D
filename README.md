# CS2D · 平面反恐精英

模块化 HTML5 5v5 战术射击游戏（ES Modules，零依赖）。顶部视角 CS，含 A/B 点爆破模式、经济系统、投掷物、AI 人机、多地图。

## 经济系统（CS2 规则）

- 起始 $800，上限 $16,000；半场换边时经济重置为 $800。
- 击杀奖励：普通 $300、AWP $100、刀 $1,500；下包/拆包各 $300。
- 回合胜利：全灭/时间耗尽 $3,250，炸弹爆炸/拆弹成功 $3,500。
- 连败补偿按队伍：$1,400 / $1,900 / $2,400 / $2,900 / $3,400。
- 死亡会清空主武器、副武器、护甲、头盔、拆弹钳、投掷物与弹药，只保留金钱；存活则保留装备。

## 视角系统

设置面板可在 俯视 / 跟随 两种视角间切换（第一人称/3D 渲染已下架，归档于 attic/）：

- **俯视**：顶部视角，相机平滑跟随并钳制地图边界，鼠标瞄准（地图固定）。
- **跟随（个人中心视角）**：玩家恒居屏幕中央，地图固定不旋转（仅人物朝向随鼠标转动）；WASD 相对朝向移动（有重量感加速）、鼠标指哪人物朝哪、←/→ 转向；zoom 拉近至 1.0 更贴近个人作战。死亡后自动回到俯视观战，复活后恢复。设置面板可调灵敏度与「减少镜头动态」缓解眩晕。

对局内：准星随武器/状态变化（刀红点、霰弹大十字、换弹变淡、空弹变红），命中停顿+伤害数字+爆头提示，受击镜头冲击；AWP 开镜平滑过渡+镜内晃动；屏幕边缘目标方向箭头、C4 计时与回合倒计时；观战显示名牌与击杀者高亮。设置面板可调 FOV（70°-110°）。低配设备自动降低渲染分辨率保证流畅。

## 娱乐模式

主菜单顶部可选择：Major 锦标赛、局域网对战、大逃杀、肉鸽地下城、Boss 战、地图编辑；另有「生涯模式」：个人+真实 CS2 战队阵容，联赛杯赛双轨、训练、转会、升降级与多赛季成长；「排位赛」：5 场定级 + MMR 天梯；「单挑模式」：1v1 MR9 对决；「电竞经理」：经营 5 人战队（转会/训练/财务/老板压力），比赛 AI 实机观战，内置 HLTV 风格评价体系（单场 HLO、赛事 MVP/EVP、最佳阵容、年度 Top 20）与时间流（日期推进/月度发薪/圣诞休赛期）。
