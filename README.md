# CS2D · 平面反恐精英

模块化 HTML5 5v5 战术射击游戏（ES Modules，零依赖）。顶部视角 CS，含 A/B 点爆破模式、经济系统、投掷物、AI 人机、多地图。

## 经济系统（CS2 规则）

- 起始 $800，上限 $16,000；半场换边时经济重置为 $800。
- 击杀奖励：普通 $300、AWP $100、刀 $1,500；下包/拆包各 $300。
- 回合胜利：全灭/时间耗尽 $3,250，炸弹爆炸/拆弹成功 $3,500。
- 连败补偿按队伍：$1,400 / $1,900 / $2,400 / $3,400。
- 死亡会清空主武器、副武器、护甲、头盔、拆弹钳、投掷物与弹药，只保留金钱；存活则保留装备。

## 娱乐模式

主菜单顶部可选择：Major 锦标赛、局域网对战、大逃杀、肉鸽地下城、Boss 战、地图编辑。
详情见 [docs/MODES.md](docs/MODES.md)。
